# ShadeDev — портфоліо

Це статичний сайт без збірки та додаткових програм. Усі файли лежать в одній папці:

- `index.html` — головна сторінка.
- `gym.html`, `cafe.html`, `business.html` — окремі сторінки демопроєктів.
- `style.css` — оформлення всього сайту та адаптація для телефонів і планшетів.
- `script.js` — зоряне небо, комети, меню, теми, анімації та кнопки.

Для перегляду відкрий `index.html`. Для публікації на GitHub Pages завантаж усі шість файлів у корінь репозиторію, щоб вони були поруч, без вкладених папок.
